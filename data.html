Sources

  • NCAA D1 saves per game leaders (population definition)
  • NCAA D1 RPI (team RPI rank, conference, record; used only for the validation test, not as a factor)
  • NCAA D1 scoreboard (daily results, Aug. 28 to Nov. 3)

Reproducing the rating

  1. Take the 80 keepers present on both NCAA leaderboards. Record games, saves, goals against.
  2. Compute shots = saves + GA; SV% = saves / shots; SOG/G = shots / games.
  3. Compute the league-average save percentage as total saves / total shots across the 80 (0.712 for 2026). Expected GA = shots × (1 − that figure). GSAA = expected − actual. GSAA/G = GSAA / games.
  4. From the results file, compute each team's SOS: two-thirds opponents' winning percentage (excluding games against the rated team, ties as half a win) plus one-third opponents' opponents' winning percentage.
  5. Rank all 80 on each of SV%, SOG/G, GSAA/G, SOS (higher is better for all four). Add the four ranks. Sort ascending; break ties on SV%.

Validation: compute the Spearman correlation between the resulting rank and the team's RPI rank. The 2026 figure is 0.252. Repeat with GA/G in place of GSAA/G and the figure should rise to roughly 0.79.

The scraping and computation code is in the GitHub repository.
